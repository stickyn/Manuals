# **How to Setup Microsoft SQL Server**

1. Go to **'https://www.microsoft.com/en-in/sql-server/sql-server-downloads'** and in the box with the title **'SQL Server 2025 (or whatever year) Developer'** click **'Download Standard Developer edition'**

2. Go through the setup wizard, and once it's done, click **'Install SSMS'** and you will be sent to **'https://learn.microsoft.com/en-us/ssms/install/install?redirectedfrom=MSDN'** and click the blue button that says **'Download SQL Server Management Studio 22 (or whatever number) installer'**

3. You will be sent to **Visual Studio Installer,** click what you want to install and when it's done, click **'Launch'**

4. Now that **'SSMS'** is open, in the **'Connect'** window, in **'Server Name'** type **'localhost'** and checkmark **'Trust Server Certificate'**

5. The **'Object Explorer'** is now open, and will work like Pgadmin4 **'> Servers'**
